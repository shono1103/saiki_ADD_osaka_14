# 基本の書き方

Markdown でスライドを書く

---

# Markdown がそのままスライドになる

`---` で区切った 1 ブロックが 1 枚のスライドです。

- **太字**、*斜体*、~~打ち消し~~、`インラインコード`
- [リンク](https://sli.dev) と画像の埋め込み
- 表やリストなど、通常の Markdown 記法はすべて使えます

| 記法 | 用途 | 備考 |
| --- | --- | --- |
| `---` | スライド区切り | 前後に空行が必要 |
| `<!-- -->` | スピーカーノート | スライドの最後に置く |
| `<v-click>` | クリックで表示 | 後述 |

<style>
/* このブロックのスタイルは、このスライドにのみ適用されます */
table { font-size: 0.9em; }
</style>

---

# スライドごとの設定

各スライドの `---` 直後に YAML を書くと、そのスライドだけに設定が効きます。

```md
一つ前のスライド

（区切り線とYAMLをここに記述）
layout: two-cols
class: text-sm
transition: fade
（区切り線）

# このスライドは 2 カラムになる
```

よく使うキー:

- `layout` — レイアウトの指定
- `class` — UnoCSS のユーティリティクラスを付与
- `transition` — このスライドへの切り替えアニメーション
- `clicks` — クリック数の明示指定
- `hide: true` — このスライドをスキップ
