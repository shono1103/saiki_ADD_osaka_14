# ファイル分割の仕組み

このデッキは章ごとにファイルを分けています。`deck/slides.md` は目次だけを持ちます。

```md
（区切り線）
src: ./pages/01-basics.md
（区切り線）

（区切り線）
src: ./pages/02-layout.md
（区切り線）
```

- 章の入れ替えは `src:` の行を動かすだけ
- 差分が章単位になり、複数人で分担しても競合しにくい
- 相対パスは呼び出し元のファイルから見た位置になる

# 分割で使える指定

<div class="grid grid-cols-2 gap-10 mt-6">

<div>

## 範囲の指定

`#` の後ろで読み込むページを絞れます。

| 書き方 | 読み込むページ |
| --- | --- |
| `x.md` | 全ページ |
| `x.md#2` | 2 枚目だけ |
| `x.md#2-4` | 2〜4 枚目 |
| `x.md#1,3` | 1 枚目と 3 枚目 |

</div>

<div>

## frontmatter の優先順位

呼び出し**元**の指定が勝ちます。

```md
（区切り線）
src: ./pages/05-closing.md
layout: center
（区切り線）
```

分割先が `layout` を持っていても、
呼び出し元の `layout: center` で上書きされます。

</div>

</div>

  循環参照（互いに <code>src:</code> で読み合う）はエラーとして検出されます
</p>
