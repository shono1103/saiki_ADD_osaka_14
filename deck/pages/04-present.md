# 発表とエクスポート

---

# 使えるコマンド

| コマンド | 内容 |
| --- | --- |
| `pnpm dev` | 開発サーバー起動（ブラウザが自動で開く） |
| `pnpm build` | 静的サイトとして `dist/` に出力 |
| `pnpm pdf` | PDF を `export/slides.pdf` に出力 |
| `pnpm png` | 各スライドを PNG で出力 |
| `pnpm notes` | スピーカーノートを PDF で出力 |

発表時のショートカット:

<ul class="!list-none grid grid-cols-2 gap-x-8 text-sm">
  <li><kbd>→</kbd> / <kbd>←</kbd> … 次へ / 前へ</li>
  <li><kbd>o</kbd> … スライド一覧</li>
  <li><kbd>f</kbd> … フルスクリーン</li>
  <li><kbd>d</kbd> … ダークモード切り替え</li>
  <li><kbd>g</kbd> … 番号を入力してジャンプ</li>
</ul>
