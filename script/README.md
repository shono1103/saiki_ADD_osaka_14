# script/ — 台本

本番デッキのもとになる**台本**を置くディレクトリです。
ここに書いた内容を AI に渡すと、`deck/slides.md` が生成されます。

## 使い方

1. `_format.md` をコピーして、新しいファイルを作る

   ```bash
   cp script/_format.md script/2026-02-15-config-validation.md
   ```

2. 中身を埋める（構成が思いつかないときは `catalog/` を先に眺める）

   ```bash
   pnpm run view              # 閲覧できるデッキ構成の一覧
   pnpm run view tech-talk    # 技術解説の構成例を開く
   pnpm run view patterns     # 1 画面パターン集を開く
   ```

3. AI に渡す

   > `script/2026-02-15-config-validation.md` の台本から `deck/slides.md` を作成してください

4. 生成されたデッキを確認する

   ```bash
   pnpm dev
   ```

## 書くときのコツ

- **ゴールは行動で書く** — 「知ってもらう」ではなく「試してみようと思える」。
  スライドの粒度と枚数がここで決まります。
- **数字と出典をセットで書く** — 台本に無い数字はスライドにも出せません。
  逆に台本に書いておけば、強調すべき箇所として扱われます。
- **時間配分を書く** — 章ごとの分数から、その章に割く枚数が決まります。
  目安は 1 枚あたり 40〜60 秒（LT は 20 秒）。
- **見せ方の希望は任意** — `catalog/patterns.md` の P 番号を書けばその形になります。
  書かなければ内容に合わせて選ばれます。
- **「触れないこと」を書く** — スコープ外を明示すると、話が膨らみません。
- **補足メモを活用する** — スライドに載せないが話したいことはスピーカーノートになります。
